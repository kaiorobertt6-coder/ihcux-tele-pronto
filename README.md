# ♿ Análise de Acessibilidade

O aplicativo foi desenvolvido pensando em usuários que podem estar com visão turva, ansiedade, dificuldade motora ou mal-estar físico.

Para melhorar a acessibilidade, utilizamos:
- Botões grandes para facilitar os toques;
- Textos maiores e legíveis;
- Alto contraste visual;
- Pouca informação por tela;
- Navegação simples e intuitiva;
- Botão de emergência sempre visível;
- Feedback constante do sistema durante o atendimento.

Essas decisões ajudam usuários com dedos trêmulos ou dificuldade de concentração a utilizarem o aplicativo com mais segurança.

---

# 🔄 Fluxo Crítico

O fluxo principal para iniciar uma consulta de urgência funciona da seguinte forma:

Home → Triagem Inteligente → Sala de Espera Virtual → Vídeo Consulta

O usuário inicia o atendimento selecionando seus sintomas na triagem. Após isso, entra em uma fila virtual até que um médico esteja disponível para realizar a consulta por vídeo.

---

# ⚠️ Prevenção de Erros
Para evitar que o usuário encerre a consulta por acidente, foram implementadas as seguintes soluções:

- Confirmação antes de encerrar a chamada;
- Botões grandes e bem separados;
- Informações claras durante toda a consulta;
- Estados do sistema visíveis;
- Interface simples para evitar confusão durante o atendimento.
